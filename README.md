# What The Fox
A Minecraft mod that fixes [MC-263591](https://bugs.mojang.com/browse/MC-263591) and [MC-147230](https://bugs.mojang.com/browse/MC-147230) to try and stop them from hurting foxes unintentionally.

## What The Mod Does
![foxexample](https://raw.githubusercontent.com/misterj05/what-the-fox/media/videos/foxexample.webp)

## Hurting Foxes Unintentionally?
If a fox ever enters a body of water while diving, [MC-263591](https://bugs.mojang.com/browse/MC-263591) will cause them to be unable to move and be underwater, which eventually causes them to drown :(. However this mod prevents that from happening!

## Mod Compatibility
Other Fox Mods should work fine as I couldn't find any that directly modify the jump function like What The Fox does. Even then, it should still be compatible. If you find any incompatibilities please let me know in Github Issues.

## Mod Updates
What The Fox is a very simple mod, while it will appear like it's not getting updates it should still work as long as the major version of Minecraft is the same, so if the version tags aren't on the newest version yet you can still give it a go and it should work.

## Known Issues
Currently, it's still a little buggy, [MC-147230](https://bugs.mojang.com/browse/MC-147230) can still trigger briefly while in the water but it's miles ahead of what vanilla is.
